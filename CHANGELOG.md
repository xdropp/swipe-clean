# Changelog

All notable changes to Swipe Clean.

## [1.4.0] - 2026-10-14

### New
- **English version.** The app follows the Windows language (English or Portuguese) and can be switched in **Settings → Language**.
- The installer is available in English and Portuguese.
- The project page on GitHub is now in English, with a Portuguese version.

### Changed
- The portable version is now called `SwipeClean-Portable-x.y.z.exe`.

## [1.3.0] - 2026-10-14

### New
- System components (Visual C++, .NET, DirectX, SDKs, drivers and Visual Studio / SQL Server parts) no longer show up as cards. Games and programs depend on them, and they took up room in the list without freeing much space.
- The summary shows how many components were hidden, and they can be shown again in **Settings → Show system components**.

## [1.2.1] - 2026-10-14

### Fixed
- The Pix support button was missing from the version downloaded from GitHub.

## [1.2.0] - 2026-10-13

### New
- Support button with a Pix QR code and copy-and-paste code generated inside the app.

### Fixed
- Steam games showed up twice on some PCs.
- The result screen showed "unknown size" when everything went to the Recycle Bin.

## [1.1.0] - 2026-10-13

### New
- **Games**, **Apps** and **Large folders** categories, with a summary screen.
- Steam and Epic Games games with cover art, last-played date and uninstall through the store itself.
- Settings: online covers, kept items, administrator rights and log folder.
- App icon, installer and portable version.

## [1.0.0] - 2026-10-13

### New
- First version: programs, Microsoft Store apps and large folders become cards to swipe.
- Mandatory review before removing, Recycle Bin for personal files and official uninstallers.
